## Lab 2: EDA and Digital Conversion Funnel Analysis (Python)

In this lab I generated a fake GA4-style session log (5,000 sessions), built a 3 step conversion funnel (session start → add to cart → purchase), cleaned the missing values with pandas, and used a seaborn correlation heatmap to look for conversion blockers.

### Files

| File | What it is |
|---|---|
| `Lab2_Conversion_Funnel_EDA.ipynb` | The notebook with all the code and outputs |
| `Lab2_Report_Mushfiqur_Rahman.pdf` | Short written report (LaTeX) |
| `ga4_sample_session_logs.csv` | The dataset generated by the notebook |
| `funnel.png` | Funnel chart |
| `heatmap.png` | Correlation heatmap |

### How to run

1. Open `Lab2_Conversion_Funnel_EDA.ipynb` in Google Colab or Jupyter Notebook.
2. Run all the cells from top to bottom. The notebook creates `ga4_sample_session_logs.csv` itself, so you don't need to download any data.
3. You need `pandas`, `numpy`, `matplotlib` and `seaborn`.

The random seed is set to 42, so you should get the same numbers as below.

### What I did

1. **Data generation:** made 5,000 sessions with user ID, device, funnel flags, page views and time on site. Deleted 50 values of `time_on_site_sec` on purpose to practise cleaning.
2. **Funnel:** counted the sessions at each step and worked out the conversion and drop-off rates.
3. **Cleaning:** filled the missing time values with the median (144 sec) and tidied the device column text.
4. **EDA:** compared conversion by device and plotted a correlation heatmap.

### Results

| Step | Sessions | Rate vs. step 1 | Drop-off |
|---|---|---|---|
| Session Start | 5,000 | 100% | – |
| Add to Cart | 1,470 | 29.4% | 70.6% |
| Purchase | 905 | 18.1% | 38.4% |

- The biggest drop is between session start and add to cart, so that is the main blocker.
- Add to cart and purchase are correlated at 0.73, and page views and time on site at 0.80.
- Page views and time on site have almost no correlation with purchase (around 0).
- The `session_start_flag` row in the heatmap is empty because it is 1 for every session.
- Conversion was about the same on desktop, mobile and tablet.

The data is randomly generated, so these patterns come from how the data was built and should not be treated as real customer behaviour.
